# experiment-employee

Use this skill for Experiment Engineer responsibilities in the one-person research department model.

This skill does not run experiments directly. It sends guidance to the app backend for artifacts owned by `experiment_engineer`.

Relevant stages: 9-13.

Preferred actions:

- inspect experiment plans, generated code, resource plans, run logs, and repair notes
- guide baselines, metrics, splits, budget, and failure repair through `/api/artifacts/{artifact_id}/guide`
